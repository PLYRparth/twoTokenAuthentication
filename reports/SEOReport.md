# Shotkut SEO Audit Report

**Website:** https://www.shotkut.com\

## Executive Summary

The website demonstrates a solid technical SEO foundation with an
overall **SEO Score of 79/100** and an **AI Visibility Score of
65/100**. The site performs well in technical SEO fundamentals such as
HTTPS, robots.txt, sitemap availability, responsive design, and page
speed. However, several improvements can further strengthen its search
visibility and user experience.

------------------------------------------------------------------------

## Positive Findings

-   Overall SEO Score: **79/100**
-   AI Visibility Score: **65/100**
-   HTTPS with valid SSL certificate
-   XML Sitemap available
-   robots.txt configured
-   Open Graph and Twitter Card metadata implemented
-   Fast loading performance (TTFB ≈ 0.002s, FCP ≈ 1.12s, LCP ≈ 1.12s)
-   Responsive design and mobile viewport configured

------------------------------------------------------------------------

## Key SEO Improvement Opportunities

### 1. Optimize Meta Description

The homepage meta description is approximately **214 characters**,
exceeding Google's recommended length (150--160 characters). A shorter,
more focused description would improve search result readability and
click-through rate.

### 2. Improve Image Optimization

Several images are missing descriptive **alt attributes**. Some images
are larger than required and a few have distorted aspect ratios.
Optimizing images will improve accessibility, page speed, and image SEO.

### 3. Increase Content Depth & Trust

The homepage is primarily product-focused. Adding educational content,
customer testimonials, licensing guides, FAQs, and creator resources
would improve topical authority and build user trust.

### 4. Reduce Cumulative Layout Shift (CLS)

The reported **CLS score is 0.327**, which exceeds Google's recommended
value of **0.1**. Reserving layout space for dynamic elements and
stabilizing page rendering will improve Core Web Vitals.

### 5. Fix Duplicate Canonical Tags

The homepage contains multiple canonical tags pointing to the same URL.
Search engines may ignore duplicate canonical declarations, so only one
canonical tag should be present.

------------------------------------------------------------------------

## Google Search Observation

Searching for **"shotkut"** currently returns results related to the
open-source **Shotcut** video editor rather than the Shotkut website,
indicating limited branded search visibility.

### Recommendation

-   Strengthen branded SEO with additional indexable content.
-   Build high-quality backlinks.
-   Publish blog articles targeting relevant search queries.
-   Increase consistent brand mentions across social platforms and
    directories.

------------------------------------------------------------------------

## Conclusion

Shotkut already has a strong technical SEO foundation. By addressing the
identified issues---particularly **meta description optimization, image
accessibility, CLS improvements, duplicate canonical tags, and richer
informational content**---the website can improve its organic search
visibility, user experience, and long-term SEO performance.
